№ 002 — Tools

道具は、3つでいい。

集中するためのタイマー。休むためのポモドーロ。続けるための実績。 余計なものは置かない。

01

クロッキータイマー

30秒・1分・5分など自由な時間設定で。 お手本観察・固定画像・タイマーのみの3モード、 ローカルフォルダ・クラウドURL・Google Drive から画像を読み込める。

02

ポモドーロ

25分作業 + 5分休憩を自動運用。 作業時間 / 休憩時間 / サイクル数は任意設定。 長時間の練習でも疲れにくい。

XP 1/sec · 自動フェーズ遷移

03

XP・実績・バッジ

クロッキー1秒=2XP、ポモドーロ1秒=1XP。 117種類のバッジ・称号・連続記録で、続けた日数を可視化する。

Level 1000+ · Streak Title

№ 003 — Note from the editor

画力は、特別な道具ではなく、たった一本の鉛筆と紙、そして「短い時間で線を決める」訓練の積み重ねでつくられる。 クロッキーは、その積み重ねを、いちばん短い単位で要求する練習だ。

KAKUZE は、その練習を毎日の習慣にするための小さな道具にすぎない。 時間を測ること、続いた日数を数えること、続けた人にだけ見える景色を可視化すること。 ツール側の仕事はそこまでで、線を引くのはあなたの仕事だ。

だから装飾は最小限に、文字は読みやすく、ボタンは押し間違えない場所に。 気が散る要素はすべて削った。あとは、はじめるだけ。
