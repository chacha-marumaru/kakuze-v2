## 8. 機能 3 列のテキスト

| 機能 | 見出し | 一文説明 |
|---|---|---|
| クロッキータイマー | 集中の時間を、設計する | 30秒・1分・5分など、自由な時間設定で。お手本観察・固定画像・タイマーのみの 3 モード。 |
| ポモドーロ | 休息を、ちゃんと取る | 25分作業 + 5分休憩を自動運用。長時間の練習も無理なく続けられる。 |

## 9. 配色（Editorial Light）の方向性メモ

- 背景: 紙のような温かみのあるオフホワイト（純白ではない）
- 本文: 純黒ではなく、僅かに紫がかった濃グレー
- アクセント: 落ち着いたインディゴ or 深い藍。蛍光色は使わない
- 状態色: 控えめ（success/warning/danger/info はノートのマーカー的なくすんだ色）
- コントラスト目標: 本文 7:1 以上（AAA寄り）、見出し 4.5:1 以上、アクセント 4.5:1 以上

## 10. タイポグラフィの方向性メモ

- ディスプレイ: Noto Serif JP（700）— 紙面的な品格、letter-spacing 引き締め、line-height 詰める
- 本文: Noto Sans JP（400/500）— 行間 1.7 前後、行長は約 38em で読みやすく
- フォント読込: preload + `font-display: swap` + size-adjust によるフォールバック調整で CLS を抑える
- 数字（XP / 時間表示）: tabular-nums 必須

## 11. モーション方向性

- 装飾アニメは入れない
- 状態の変化（hover / focus / press / open / close / load）にのみモーションを使う
- duration: fast 150ms / base 250ms / slow 400ms
- 共通 ease: cubic-bezier(0.2, 0, 0, 1)
- prefers-reduced-motion: reduce で全アニメ即時化（実装済み）
