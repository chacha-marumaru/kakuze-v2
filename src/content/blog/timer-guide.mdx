## KAKUZEタイマーとは

KAKUZE には **クロッキータイマー** と **ポモドーロタイマー** の2種類のタイマーが搭載されています。どちらも練習をサポートしつつ、XP（経験値）を獲得してレベルアップできる仕組みになっています。

## クロッキータイマーの使い方

### 基本操作

1. `/app` ページを開く
2. 「クロッキー」タブを選択
3. 時間を設定する（30秒 / 60秒 / 2分 / 5分 から選択）
4. 「スタート」ボタンを押す
5. タイマーが終了するとチャイムが鳴りXPが加算される

### 時間設定の使い分け

| 時間 | 向いている用途 |
|------|----------------|
| 30秒 | シルエット・動きの把握 |
| 60秒 | 全身のバランス・重心 |
| 2分 | 部位ごとの形・細部 |
| 5分 | じっくり構図を作る |

初心者は **60秒** から始めるのがおすすめです。慣れてきたら30秒に短縮していくと観察スピードが一気に上がります。

## ポモドーロタイマーの使い方

### 基本操作

1. 「ポモドーロ」タブを選択
2. 作業時間と休憩時間を設定する（デフォルト: 25分 / 5分）
3. 「スタート」ボタンを押す
4. 作業セッションが終わると自動的に休憩タイマーに切り替わる

### ポモドーロとお絵描きの相性

- 25分の作業セッションを「模写」「練習ページ仕上げ」「リファレンス収集」などに割り振ると集中しやすい
- 休憩中に手や目を休めることで、長時間の練習でも疲弊しにくくなる

## XPとレベルシステム

KAKUZE ではタイマーを使うたびにXP（経験値）が貯まります。

- **クロッキー**: 2 XP / 秒
- **ポモドーロ**: 1 XP / 秒

XPが貯まると自動的にレベルアップし、練習の積み重ねを目に見える形で確認できます。毎日の練習を「記録」として残す感覚で使ってみてください。

## まとめ

KAKUZEのタイマーはシンプルな操作で始められ、練習量をXPとして記録してくれます。目的に合った時間設定でスキマ時間を活用しながら、毎日少しずつ練習を積み重ねていきましょう。
